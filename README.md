# resume
Create dynamic resume

## How to Run

To generate your resume, follow these steps:

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Script
```bash
node resume.js
```

### 3. Output
The script will generate a Word document (.docx) file with your formatted resume based on the configuration in `resume.js`.

### Requirements
- Node.js (v12 or higher)
- docx package (automatically installed via npm)
